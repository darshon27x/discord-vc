## ✨ Features

- 🌐 **Web Dashboard:** Clean and responsive UI for managing accounts.
- 👥 **Multi-Account Management:** Add, monitor, and control multiple accounts simultaneously.
- 🔐 **Authentication & Security:** PBKDF2 password hashing and secure session management.
- 👑 **Role System:** Admin and User roles with customizable token limits.
- 🎙️ **Voice Channel Features:** Join and keep accounts active in voice channels.
- 📂 **JSON Storage:** Lightweight data storage under the `data/` directory.

## 🛠️ Installation & Setup

### 1. Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v16 or higher) installed on your system.

### 2. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
cd YOUR_REPOSITORY_NAME
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start the Application
```bash
npm start
```

Once started, open your browser and navigate to:
```text
http://localhost:3000
```
*(or the port specified in your console output)*
